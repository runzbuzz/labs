## 🛠️ Repository Structure & Usage

To keep our research isolated, organized, and reproducible, this repository operates as a monorepo structured by project folders: 

1. **Self-Contained Dependencies:** Each project folder contains its own dependency management system (e.g., requirements.txt, package.json, or Cargo.toml). Do not install packages at the root level.
2. **Dedicated Readmes:** Navigate into any project folder to find a standalone, lightweight configuration guide outlining how to spin up and test that specific environment locally.
